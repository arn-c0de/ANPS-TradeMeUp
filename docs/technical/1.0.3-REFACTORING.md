# 1.0.3 Refactoring – Part 1 & Part 2 Summary

**Date:** 2026-01-25  
**Scope:** GUI `app.py` modularization.

---

## Part 1 (initial)

- **Utils:** `routing.py` (tab-from-hash, valid tab IDs) and `callbacks.py` (`safe_callback`) extracted under `src/gui/utils/`.
- **CSS/JS:** Dark theme moved to `theme_dark.css`; React suppress and chart splitters to `react_suppress.js` and `chart_splitters.js`. `index_string` reduced to a minimal HTML shell.
- **Charts:** `overlay_utils.py` and `chart_utils.py` added; selected chart callbacks moved to `callbacks/charts_callbacks.py` and registered via `register_charts_callbacks(app)`.
- **Tabs:** Each tab has `register_callbacks(app)`. Dashboard, News, and Control callbacks moved into their tabs; others still in `app.py` (stubs in place).
- **Common:** URL–tab routing and live-status callbacks moved to `callbacks/common.py` and registered via `register_common_callbacks(app)`.

## Part 2 (full migration)

- **Tab callbacks:** All remaining tab callbacks moved from `app.py` into their tabs:
  - **Predictions:** Entity filter, table, modal, refresh, loading state, modal content → `tabs/predictions.py`.
  - **Simulations:** Entity options, table, create, sync, delete, refresh, clear-all modal → `tabs/simulations.py`.
  - **Statistics:** `_resolve_stats_date_range` plus metrics, date range, buttons, charts, sentiment, impact, top entities, modals, index trends, stock predictions, `open_news_prediction_detail` → `tabs/statistics.py`.
  - **Control:** Pipeline/backfill callbacks (single-agent toggle, pipeline log, run full/quick/backfill, selective backfill, recent executions) added to existing Control callbacks in `tabs/control.py`.
  - **Testing:** Dynamic agent-test callbacks, test-all, summary, reset, error modal → `tabs/testing.py`.
  - **System:** Agent status, DB stats, pipeline stats → `tabs/system.py`.
  - **Settings:** `LLM_MODELS`, load/save LLM, pipeline phase settings, open settings, custom dates, delete confirmation, execute delete → `tabs/settings.py`.
- **Charts package:** `callbacks/charts/` package added:
  - `core.py`: ESC, fullscreen, quad mode, open-ticker, migrate tab IDs, sync overlays (from former `charts_callbacks.py`).
  - `extended.py`: Price cache, tab buttons, overlay modal/lists, add/update overlays, infinite scroll, render display, panel settings, config modal, quick edit, favorites, etc.
  - `__init__.py`: `register_charts_callbacks(app)` registers core + extended.
- **app.py:** Reduced to ~135 lines: imports, Dash init, `index_string`, layout (Location, Intervals, Stores, Navbar, Tabs), and registration of `register_common_callbacks`, `register_charts_callbacks`, and each tab’s `register_callbacks`. No callback definitions remain in `app.py`.

## Result

- `app.py` is minimal: init, layout, and callback registration only.
- All tab-specific callbacks live in their tabs; chart callbacks in `callbacks/charts/`.
- Dark background enforced via `.bg-dark` and `.min-vh-100` in `theme_dark.css`.

## Next steps (optional)

- Optionally split `callbacks/charts/extended.py` into smaller modules (e.g. `tabs`, `overlays`, `infinite_scroll`, `render`, `panels`) for easier maintenance.
- Extract layout (Location, Intervals, Stores, Navbar, Tabs) into `layout.py` if desired.
